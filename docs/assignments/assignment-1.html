Source: Veri Bilimi ve Endüstri Mühendisliği Üzerine Sohbetler - Baykal Hafızoğlu & Erdi Daşdemir

(a) BRIEF SUMMARY

The world of data analytics is divided into four fundamental stages: “descriptive,” in which we simply visualize the data and understand the situation; “diagnostic,” in which we identify the causes of events; “predictive,” in which we predict the future using techniques like machine learning; and lastly, “predictive,” in which we can actually execute the actions using optimization models. On the more practical side, I have gained knowledge of the golden rules that need to be followed when I leave school and start working on actual projects. Firstly and most obviously, the problem has to be well defined and linked to specific KPIs. Additionally, the analytical models that we develop after spending countless hours cannot simply be left idle on our own computers; they need to be deployed live with a UI. Instead of creating complex models, proceeding with simplicity so that the user understands the logic and constantly receiving feedback from them is vital to the success of the application. The most surprising thing to me was that even in large projects, the code that deals with the analysis and optimization that we are concerned with is merely 1% of the entire project. While the other 99% is spent gathering information, dealing with the database, and creating the interface, the realization that the application is pointless without this magical 1% was an eye-opener.

Questions & Answers

1. Open-Ended Question

Question: During the presentation, Dr. Baykal Hafızoğlu states that the core optimization or analytical model often constitutes only about 1% of the total work in a real-world software project. What makes up the remaining 99% of the effort, and why is that 1% still considered the most critical component despite its small size?

Answer: The remaining 99% of the effort consists of tasks necessary to make the model accessible and functional for the end-user. This includes data wrangling, database management, error handling, deployment, and especially building a clean, user-friendly Graphical User Interface (GUI). Although the analytics code is only 1% of the total lines of code, it acts as the “engine” of the application. Without the 99% infrastructure, end-users cannot interact with or adopt the solution; however, without that 1% core analytical model, the entire application would be useless because it wouldn’t solve the actual business problem.

2. Multiple-Choice Question

Question: Dr. Hafızoğlu categorizes the analytics world into four main stages: Descriptive, Diagnostic, Predictive, and Prescriptive. Based on his explanations, which of the following accurately matches the analytics stage with its corresponding methodology or goal?

A) Descriptive Analytics: Using hypothesis testing to determine the root causes of why a factory’s production defect rate increased.

B) Predictive Analytics: Creating a mathematical optimization model to decide how much safety stock a company should keep.

C) Diagnostic Analytics: Visualizing historical data using bar charts and box plots to show past sales trends.

D) Prescriptive Analytics: Utilizing optimization solvers to generate actionable decisions and provide a “prescription” on what steps a business should take.

E) Descriptive Analytics: Using machine learning algorithms to forecast next month’s customer demand.

Answer: D) Prescriptive Analytics
